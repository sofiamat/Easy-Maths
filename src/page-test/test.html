Question 1/8

Dans un triangle rectangle, quelle est la relation entre les côtés a, b et l'hypoténuse c?

le théorème de Pytagore indique que a² + b² = c², où c'est l'hypoténuse.

Question 2/8

Quel est le côté le plus long dans un triangle rectangle?

l'hypoténuse est toujours le côté le plus long, opposé à l'angle droit.

Question 3/8

Un triangle a des côtés de 3, 4 et 5. Quelle est la longueur de l'hypoténuse?

5 est le côté le plus long, donc c'est l'hypoténuse. On vérifie : 3² + 4² = 9 + 16 = 25 = 5².

Question 4/8

Si a = 16 et b = 30, quelle est la valeur de c²?

c² = a² + b² = 16² + 30² = 256 + 900 = 1156.

Question 5/8

La réciproque du théorème de Pythagore permet de vérifier :

Si c² = a² + b², alors le triangle est rectangle. C'est la réciproque du théorème.

Question 6/8

Un triangle a des côtés 5, 12 et 13. Est-il rectangle?

13² = 169 et 5² + 12² = 25 + 144 = 169. Donc c² = a² + b², le triangle est rectangle!

Question 7/8

Si c² = 50 et a = 5, quelle est la valeur de b²?

a² + b² = c², donc b² = c² - a² = 50 - 25 = 25

Question 8/8

Le théorème de Pythagore s'applique à :

Le théorème de Pythagore s'applique uniquement aux triangles rectangles.
